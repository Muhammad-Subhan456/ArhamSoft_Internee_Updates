# Python Utility Toolkit

A collection of Python utility classes and functions demonstrating:

- Object-Oriented Programming
- Type Hints
- Logging
- pathlib
- JSON Serialization
- datetime
- Counter
- defaultdict
- Modular Project Structure

## Features

- BankAccount and SavingsAccount classes
- Custom Exceptions
- Transaction persistence using JSON
- Transaction filtering by date
- Category statistics using Counter
- Category grouping using defaultdict
- Logging to console and file
